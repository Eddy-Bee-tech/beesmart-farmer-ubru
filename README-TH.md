# BeeSmart Farmer PWA รุ่น 1.9.4 – ปฏิทินกิจกรรม

รุ่นนี้เพิ่มโมดูลปฏิทินกิจกรรม โดยคง IndexedDB เดิม (`beesmart-web-v1`) และโครงสร้างรายการเดิมไว้

## สิ่งที่เพิ่ม
- ปฏิทินรายเดือน พร้อมเปลี่ยนเดือนและกลับไปวันนี้
- จุดสีบอกกิจกรรมตรวจรัง / ให้อาหาร / เก็บเกี่ยว / รายรับ / รายจ่าย
- เลือกวันที่เพื่อดูรายการกิจกรรมของวันนั้น
- กรองตามฟาร์ม
- กิจกรรมเดิมเชื่อมปุ่มแก้ไขและลบจากหน้าปฏิทินได้
- ทำงานร่วมกับ PWA และ service worker; ปฏิทินอ่านข้อมูลจาก IndexedDB ในอุปกรณ์

## ติดตั้ง/เผยแพร่
ใช้ไฟล์ทั้งหมดใน ZIP วางที่ root ของ static hosting (HTTPS) แล้วเปิดเว็บครั้งแรกเพื่อให้ service worker cache แอป

## หมายเหตุ
ปฏิทินเป็นมุมมองข้อมูลจากกิจกรรมและรายการบัญชีที่มีอยู่ ไม่ได้เพิ่ม/แก้ schema หรือสร้างรายการอัตโนมัติ
